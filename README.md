# CSS Positioning Journal

Henry's Gucci Journal: a styled two-column journal page built for the Inclass-02 CSS Positioning exercise.

**Author:** Ibrahim Mackey
**Live page (CODD):** https://codd.cs.gsu.edu/~imackey1/web/inc/inc2/index.html

## What it demonstrates
- CSS box model with a global `box-sizing: border-box` reset
- Float-based two-column layout (25% sidebar / 75% content) with a clearfix on the container
- Picture-frame images using border, padding and box-shadow
- Responsive design with a mobile media query (max-width: 768px) that stacks the columns

## Special Features
1. **Custom Color Theme and Typography** - Documented six-color palette plus the Poppins Google Font
2. **Hover Effects and Transitions** - header title, friends list, journal cards and images
3. **Extra Responsive Breakpoint** - tablet range (769px to 1024px) with its own layout adjustments

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure (header, sidebar, content, footer) |
| `journal_starter.css` | All styling |
| `knife.jpg`, `cupcake.jpg` | Journal entry images |

## Run locally
Open `index.html` in any modern browser. Keep the HTML, CSS and images in the same folder.
